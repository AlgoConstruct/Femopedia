# Aura Companion

Build a modern, premium, production-ready landing page for an AI Women's Health platform.

The website should feel like a combination of Apple, Notion, Linear, Stripe, and Headspace.

Avoid looking like a hospital website or a pink-themed "women's app." Instead, make it elegant, trustworthy, calm, and technologically advanced.

The website should communicate safety, trust, emotional warmth, and intelligence.
